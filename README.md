\# Student Performance Predictor



A Python Flask web application that estimates student marks based on previous marks, attendance, and daily study hours.



\## Features

\- Predict estimated marks out of 100

\- Show performance category

\- Give study improvement suggestions

\- Simple web interface



\## Technologies Used

\- Python

\- Flask

\- Pandas

\- Scikit-learn

\- HTML and CSS



\## How to Run

1\. Install Python.

2\. Install dependencies:

&#x20;  pip install -r requirements.txt

3\. Run the application:

&#x20;  python app.py

4\. Open http://127.0.0.1:5000 in your browser.



\## Note

This is an educational demo using sample data. Predictions are estimates, not guarantees.
